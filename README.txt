BAYSIDE FINE JEWELRY — Responsive Single Page Website

Technologies: HTML5, CSS3, Bootstrap 5.3.3, jQuery 3.7.1 and JavaScript.
Open index.html in a browser to view the website.
The assets folder contains all supplied jewelry images.
Responsive breakpoints are included for desktop, tablet and mobile.
The hero carousel and responsive navigation use Bootstrap; jQuery handles smooth scrolling and newsletter form behavior.
Internet is required for Bootstrap and jQuery CDN resources.
